# Hash POS Desktop — نظام هاش المتكامل لإدارة المطاعم ونقاط البيع

**الإصدار:** 1.0.16
**الشركة المطورة:** Techier

نظام ديسكتوب (Desktop Application) متكامل وسريع مصمم خصيصاً للمطاعم والكافيهات ومحلات التجزئة، مبرمج باستخدام بيئة **Electron**. يركز النظام على العمل بشكل **محلي ولا مركزي (Offline-First)** دون الحاجة للاعتماد الدائم على الإنترنت، مع تقديم مزايا سحابية اختيارية، ومحرك مالي ومحاسبي يغنيك عن الأنظمة المحاسبية المعقدة.

---

## 🌟 مميزات النظام وما يميزه عن المنافسين

يتفوق هذا النظام على العديد من أنظمة الكاشير التقليدية (POS) في السوق بفضل هندسته الفريدة:

1. **لا يتطلب إنترنت للعمل الأساسي (Offline-First):**
   قاعدة البيانات محلية وتعمل بكفاءة عالية جداً. المبيعات، المرتجعات، المصروفات، والمخزون كلها تسجل محلياً، مما يضمن عدم تعطل المطعم أو المحل عند انقطاع الإنترنت.
2. **مزامنة شبكية داخلية (LAN P2P Sync):**
   بدون سيرفرات سحابية مكلفة! النظام مزود بمحرك يعتمد على بروتوكولات (UDP/HTTP) للبحث التلقائي عن أجهزة الكاشير الأخرى في نفس الشبكة المحلية (LAN) ومزامنة البيانات معها في الوقت الفعلي (دعم الأجهزة المتعددة).
3. **حل محاسبي متكامل (Mini-ERP) وليس مجرد كاشير:**
   يتجاوز النظام فكرة إدخال الطلبات؛ حيث يتضمن شجرة حسابات مبسطة تتواصل بذكاء مع المبيعات والمشتريات والمصروفات الإدارية والرواتب لإنتاج **تقارير أرباح وخسائر (Profit & Loss)** فورية دقيقة تدعم الأرصدة المتعددة (الكاش vs البنك).
4. **تكامل مع الواتساب الذكي (WhatsApp Web JS):**
   يتيح النظام ربط رقم الواتساب الخاص بالفرع لإرسال ملخصات الإغلاق اليومي، سندات المصروفات، وتنبيهات النظام للمدير المالي أو مالك المطعم تلقائياً كرسائل (أرقام وحيّة بتنسيق ممتاز + صور).
5. **لا توجد اشتراكات شهرية إلزامية للسحابة:**
   يقدم التكامل مع **Google Drive** لرفع نسخ احتياطية (Backups) تلقائياً لحساب المالك مجاناً، ليضمن أمان البيانات دون تكاليف خوادم خارجية.
6. **دعم هيئة الزكاة والدخل (ZATCA Phase 2):**
   محرك متكامل (`zatca-engine`) لتوليد فواتير إلكترونية متوافقة بالكامل مع المرحلة الثانية (الربط والتكامل) في المملكة العربية السعودية.

## 🚀 قدرات النظام ووحداته الرئيسية (الـ Modules)

### 1- وحدة نقاط البيع (POS) والكاشير 🛒
- واجهة كاشير سريعة مصممة لتحمل ضغط العمل العالي (`pos.html`).
- تقسيم المدفوعات في فاتورة واحدة (جزء كاش وجزء شبكة/بطاقة).
- نظام المرتجعات (Returns) المرتبط بشكل عكسي مع المخزون والصندوق.
- تعليق الطلبات وإدارة الطاولات أو طلبات التيك أواي.

### 2- النظام المحاسبي الشامل (Accounting & Financials) 📊
- تتبع حركة الخزينة (الصندوق النقدي) مقارنة بحركة الحسابات البنكية بشكل مستقل لكل عملية.
- صفحة مخصصة لسندات المصروفات (`acc-expenses.html`) مع إمكانية تحويل السند لـ PDF وإرساله للمدير بالواتساب.
- سندات الصرف والقبض، إدارة حسابات البنوك، التحويلات اليدوية بين البنك والصندوق.
- تقرير الأرباح والخسائر الصافي (Net Profit) بعد خصم المشتريات، المصروفات الإدارية، رواتب الموظفين التشغيلية والمرتجعات.

### 3- إدارة المخزون والتصنيع (Inventory & Recipes) 📦
- دعم تعدد المستودعات (Multi-Warehouse).
- خصم دقيق على مستوى المكونات (Raw Materials): عند بيع "برجر" يتم خصم "خبز، قطعة لحم، صوص" تلقائياً بالجرامات أو الحبة.
- أوامر الصرف المستودعي للمطبخ وتسويات جردية.

### 4- المشتريات والموردين (Purchases & Suppliers) 🚚
- إدخال فواتير المشتريات وتأثيرها المباشر على زيادة المخزون ونقصान في السيولة (الصندوق/البنك).
- دليل الموردين وتتبع كشوفات الحسابات الخاصة بهم.

### 5- الموارد البشرية والرواتب (HR) 👥
- نظام إدارة الموظفين وتسجيل الرواتب واستقطاعات الجزاءات/الخصومات.
- ترتبط الرواتب والبدلات مباشرة بدفتر الأستاذ (القيود المحاسبية) لتخفيض أرباح الشهر تلقائياً.

### 6- واجهة وتطبيقات المطبخ (KDS & Production) 🍳
- شاشة المطبخ لاستلام الطلبات (Kitchen Display System)، لتنظيم سير العمل وتحضير الطلب وتسليمه بضغطة زر دون الحاجة لطباعة الورق كخيار بديل.

### 7- الإحصائيات والتقارير (Dashboards & Reports) 📈
- رسومات بيانية تفاعلية (Chart.js) لمقارنة الإيرادات بالمصروفات.
- تقارير إغلاق الوردية والمبيعات المفصلة للضرائب أو التحليل الإداري.

## 🖨️ الأجهزة المدعومة والعتاد

1. **الطابعات الحرارية (Thermal Printers):**
   حل هندسي ذكي جداً مدمج، يتخطى مشاكل تعريفات ويندوز المزعجة. النظام يجبر تخطيط الصفحة (Layout) على `80mm` داخلياً ويحتوي على أوامر `scheduleSilentPrint` للطباعة بالخلفية بدون نوافذ مزعجة (Silent Printing). يدعم كافة طابعات الإبسون وأي طابعة حرارية 80 مم أو 58 مم.
2. **طابعات المطبخ (Kitchen Printers):**
   دعم توجيه أقسام المنيو لطابعات فرعية حسب الإعدادات.
3. **قارئ الباركود (Barcode Scanners):**
   تكامل فوري في خانة البحث في المبيعات والمخزون، يعمل بتقنية HID كالكيبورد.
4. **أدراج الكاشير (Cash Drawers):**
   يفتح تلقائياً مع أوامر الطباعة كجزء من أكواد الطابعة الافتراضية.
5. **شاشات اللمس (Touch Screens):**
   تصميم الواجهة يعتمد على CSS متجاوب وأزرار كبيرة مناسبة لنقرات شتى مقاسات شاشات نقاط البيع القياسية (15 بوصة وأكبر).

## 💻 قسم المطورين (Developers Guide)

تم بناء التطبيق على بيئة سطح مكتب باستخدام تقنيات الويب الحديثة مما يجعله سهل الصيانة والتحديث.

### 🛠️ التقنيات المستخدمة (Tech Stack)
* **المحرك الأساسي:** Electron (نسخة 41.0.3) & Node.js
* **واجهة المستخدم (Frontend):** 
  * HTML5 / CSS3 بستايل تفاعلي و Vanilla JS.
  * لا يتم استخدام إطار عمل معقد مثل React أو Vue عمداً لضمان سرعة الاستجابة بأجهزة الكاشير الضعيفة.
  * أيقونات `@phosphor-icons/web` وخطوط `@fontsource/cairo`.
* **قاعدة البيانات:** 
  * يعتمد محلياً على JSON Tree Object Mapping (في ملف `pos_database.json`). مدمج أيضاً قدرات للـ `better-sqlite3` لدعم السيناريوهات المستقبلية.
* **التزامن الشبكي (Networking):**
  * يتم عبر خادم `http` مبني فوق Node.js مضاف في `main.js` على بورت `41235` ومحرك UDP للبث المباشر للأجهزة الفرعية لاكتشاف بعضها `dgram`.
* **الربط الخارجي:**
  * بوابة دفع فاتورة `Fatora`.
  * هيئة الزكاة لدعم XML باستخدام `zatca-xml-js`.
  * `googleapis` لرفوعات 구글 درايف.
  * `whatsapp-web.js` لحقن متصفح كروميوم مخفي كعميل واتساب.

### 🚀 خطط التشغيل وبيئة التطوير
تأكد من تنصيب `Node.js` (يفضل إصدار LTS) ثم:

1. **تثبيت الحزم المشغلة:**
   ```bash
   npm install
   ```

2. **تشغيل التطبيق في وضع التطوير (Run Local):**
   ```bash
   npm start
   ```

3. **محاكاة طباعة الإيصالات كـ PDF (بدون طابعة حقيقية):**
   يسمح هذا النمط باختبار شكل الإيصال بدلاً من إهدار الورق (سيتم تصدير الإيصالات لمجلد بصيغة PDF).
   ```bash
   npm run start:sim-print
   ```
   *أو لفتحها تلقائياً بعد إنشائها:*
   ```bash
   npm run start:sim-print-open
   ```

4. **تشغيل اختبارات النظام (Unit & E2E):**
   تم بناء الاختبارات التلقائية باستخدام `Vitest` و `Playwright`.
   ```bash
   npm run test:all
   ```

5. **بناء النسخة النهائية (Build Installer):**
   يستخدم `electron-builder` لبناء ملف تثبيت للعميل (EXE Windows):
   ```bash
   npm run build
   ```

### 🧠 ملاحظات هامة في شيفرة النظام (Code Architecture)
* **ملف `main.js`**: يدير نوافذ البرنامج، سيرفر HTTP المدمج لمشاركة قاعدة البيانات، البث (Broadcast) لأجهزة الشبكة لدعم الـ LAN Sync، ووظيفة الطباعة (Print Server).
* **ملف `database.js`**: الـ Wrapper المسؤول عن قراءة وكتابة وتحديث المخزون بشكل منطقي، يحتوي على دوال الحسم المباشر (Deductions) للوصفات (Recipes).
* **ملف `acc.js`**: هو قلب "النظام المحاسبي" الصغير؛ يحسب كافة الموازنات بطريقة دمج وتجميع الصناديق وحساب المصاريف في الوقت الفعلي في الواجهة.
* **الفاتورة وطباعتها (`thermal-receipt-updated.js`)**: الكلاس والمنطق المسؤولان عن تجهيز ستايلات وتقسيم أسطر الفاتورة وطباعتها حرارياً بشكل مقصوص ومتأنق دون الاعتماد الكلي على متصفح ويندوز الافتراضي للطباعة.
