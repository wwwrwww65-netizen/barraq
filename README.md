##### 1. إصلاح مشكلة إرسال الصور في واتساب المتخفي (Bot Mode) - Race Condition
**التأريخ:** أبريل 2026  
**الملفات المتأثرة:** `main.js` (السطور 1811-1920, 1663-1675)  
**الأولوية:** 🔴 حرجة - تؤثر على إرسال المستندات للإدارة

**المشكلة:**  
عند إرسال صورتين متتاليتين عبر واتساب (الأولى للموظف والثانية للمدير)، كانت الرسالة الأولى تُرسل بنجاح (صورة + نص)، لكن الرسالة الثانية تُرسل كنص فقط بدون صورة.

**السبب الجذري (Root Cause):**  
- **Race Condition** بين عملية لصق الصورة (`Ctrl+V`) وعملية واتساب الداخلية لتعبئة النص من URL
- عند تحميل URL مثل `https://web.whatsapp.com/send?phone=XXX&text=YYY`، يقوم واتساب بتأخير زمني لتعبئة النص في حقل الإدخال
- النظام كان يلصق الصورة بسرعة قبل اكتمال تعبئة النص
- عندما يُعبأ النص لاحقاً، كان يقوم بمسح معاينة الصورة (Image Preview) واستبدالها بالنص فقط
- المشكلة تتفاقم عند إرسال رسائل متعددة لأن الحالة (State) لا يتم تنظيفها بين الإرسالات

**طريقة الإصلاح (3 طبقات حماية):**

**أ) تحسين آلية الانتظار الذكية (Smart Polling) - `main.js` السطور 1825-1852:**
- زيادة عدد المحاولات من 20 إلى **40 محاولة**
- التحقق من **استقرار النص** (لا يتغير) لمدة 300ms إضافية
- إضافة logging لتتبع حالة النص

**ب) زيادة أوقات الانتظار - `main.js` السطور 1861-1868:**
- انتظار قبل لصق الصورة: من 400ms → **600ms**
- انتظار بعد لصق الصورة (لظهور المعاينة): من 2000ms → **3000ms**
- إضافة **فحص معاينة الصورة** قبل الإرسال للتأكد من وجودها

**ج) إعادة تحميل الصفحة بين الرسائل - `main.js` السطور 1900-1913:**
- إعادة تحميل WhatsApp Web بعد كل رسالة
- ضمان **نظافة الحالة** (Clean State) للرسالة التالية
- انتظار 2000ms بعد إعادة التحميل

**د) زيادة وقت الانتظار في Queue - `main.js` السطور 1663-1675:**
- للرسائل مع صور: **6000ms** (بدلاً من 4000ms)
- للرسائل النصية فقط: **4000ms**

**النتيجة:**  
✅ الموظف يتلقى: صورة + نص  
✅ المدير يتلقى: صورة + نص  
✅ لا مزيد من Race Conditions  
✅ إرسال موثوق ومستقر للرسائل المتعددة

##### 2. نظام إشعارات واتساب الجميل (WhatsApp Notification System)
**التأريخ:** أبريل 2026  
**الملفات المتأثرة:** 
- `main.js` (السطور 1682-1980) - إضافة إرسال النتائج للـ Renderer
- `wa-notification.js` (ملف جديد - 439 سطر)
- `staff.html` (السطر 687) - إضافة السكربت
- `accounting.html` (السطر 303) - إضافة السكربت

**الميزة الجديدة:**  
إشعارات جميلة أسفل الشاشة لتأكيد إرسال واتساب مع تفاصيل كاملة.

**المواصفات:**

**أ) إشعار النجاح (Success Toast):**
- 🎨 تصميم أخضر متدرج مع أيقونة ✓
- 📱 عرض الرقم المرسل إليه
- ⏱️ إغلاق تلقائي بعد 5 ثواني
- ✨ أنيميشن دخول/خروج سلس

**ب) إشعار الفشل (Failure Toast):**
- 🎨 تصميم أحمر متدرج مع أيقونة ✗
- 🔄 زر "إعادة المحاولة" - يعيد الإرسال مباشرة
- 📥 زر "تحميل المستند" - يحمل الصورة كـ JPG
- ⏸️ لا يُغلق تلقائياً (يتطلب تدخل المستخدم)
- 📊 شريط تقدم يوضح الوقت المتبقي

**ج) التصميم التقني:**
```css
.wa-toast {
  background: linear-gradient(135deg, #1e293b 0%, #0f172a 100%);
  backdrop-filter: blur(20px);
  box-shadow: 0 20px 60px rgba(0, 0, 0, 0.5);
  border-radius: 16px;
  min-width: 380px;
  direction: rtl;
}
```

**د) آلية العمل:**
1. `main.js` يُرسل النتيجة عبر `event.sender.send('wa-send-result', sendResult)`
2. `wa-notification.js` يستمع للحدث `ipcRenderer.on('wa-send-result', ...)`
3. يعرض الإشعار المناسب حسب الحالة (success/failure)
4. في حالة الفشل، يحفظ البيانات في `pendingFailedSends Map` لإعادة الإرسال

**النتيجة:**  
✅ تأكيد مرئي جميل لكل عملية إرسال  
✅ إمكانية إعادة المحاولة عند الفشل  
✅ تحميل المستند كصورة عند الحاجة  
✅ تجربة مستخدم احترافية ومطمئنة
